## 📋 Deployment Steps (5 Minutes)

### Step 1: Go to Streamlit Cloud
🔗 **Open this link:** https://share.streamlit.io/

### Step 2: Sign In
- Click **"Sign in"** (top right)
- Choose **"Continue with GitHub"**
- Authorize Streamlit Cloud to access your GitHub

### Step 3: Create New App
- Click the **"New app"** button
- You'll see a form with three fields

### Step 4: Fill in the Details

**Copy and paste these exact values:**

```
Repository: ritigya108/Mental_Health_Project
Branch: main
Main file path: streamlit-app/Home.py
```

**Screenshot of what to fill:**

### Step 5: Advanced Settings (Optional)
- Click **"Advanced settings"** if you want to customize
- **App URL:** You can set a custom name like `mindcare-ritigya`
- Leave other settings as default

### Step 6: Deploy!
- Click the **"Deploy!"** button
- Wait 2-3 minutes for deployment

## 🔧 Troubleshooting

### If deployment fails:

**Check requirements.txt:**
Make sure `streamlit-app/requirements.txt` has all dependencies:
```
streamlit==1.29.0
pandas==2.1.3
numpy==1.26.2
plotly==5.18.0
vaderSentiment==3.3.2
python-dotenv==1.0.0
```

**Check file path:**
Make sure you entered: `streamlit-app/Home.py` (not just `Home.py`)

**Check branch:**
Make sure you selected `main` branch

### If app shows errors:

1. Check the **Logs** in Streamlit Cloud dashboard
2. Make sure all imports are in requirements.txt
3. Redeploy by clicking "Reboot app"
